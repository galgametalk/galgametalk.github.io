什么是 Galgame 游戏？

Galgame 是 Girl Game 的缩写，指以角色互动与剧情为核心的日式视觉小说／恋爱冒险游戏。玩家主要通过阅读文本、欣赏立绘与 CG，并在关键节点做出选择，进入不同的路线与结局。

需要说明的是，中文圈里「Galgame」一词有时被用来指代成人向游戏，这与其在日本的原始用法存在差异。本站讨论的是以剧情、角色与情感体验为主的全年龄作品。

发展简史

  1. 1990 年代：雏形期

    恋爱模拟与文字冒险奠定基础，《心跳回忆》等作品影响深远，现代形态大致在 2000 年前后成形。

  2. 2000 年代：改编黄金期

    Key 社的《CLANNAD》等作品推动了「泣系」风潮，并由京都动画等公司改编为动画，成为游戏与动画联动运营 IP 的经典案例。

  3. 2010 年代：多元化

    科幻、悬疑题材的视觉小说走向大众；国产 Galgame 借助线上平台与众筹逐步成长，《三色绘恋》是被频繁提及的代表之一。

  4. 2020 年代至今：移动端与中文化

    手机端体验日趋成熟，越来越多经典作品获得中文版本，入门门槛明显降低。
